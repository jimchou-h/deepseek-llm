## MODIFIED Requirements

### Requirement: DeepSeek blue accent

The chat shell SHALL use Signal `#3BA7FF` as the primary accent for selected session state, primary actions, and key interactive highlights. Ant Design primary SHALL match Signal. Default application chrome SHALL use the ink-console palette (Ink / Panel / Deck / Line / Text / Dim), not a light page canvas. The palette SHALL avoid purple-on-white AI cliché theming and SHALL avoid black-plus-acid-green HUD cliché theming.

#### Scenario: Selected session affordance

- **WHEN** a session is active
- **THEN** it is visually distinguished using the Signal accent (or a derived token)
